## 马来供应商(Asianoverland Via QTECH) FAQ

- 供应商是哪个国家的公司（国际供应商回答）？
    - **马来供应商 Asianoverland  技术通道： QTECH**
- 供应商是与我们哪个公司主体签约？
    - **Heytrip**
- 价格是否有佣金相关的说法？
    - **没有**
- 酒店总量有多少？
    - **355个 （只有马来西亚的酒店）**
- 有价酒店有多少？
    - **256个**
- 供应商的报价接口是否有价格类型参数，比如手机价，pc价？
    - **没有**
- 供应商主要价格优势比较好的地区有哪些（国际供应商回答）？
    - **马来西亚**
- 供应商的实时报价接口响应速度如何，平均500毫秒？
    - **平均300-500毫秒 （单个酒店）**
- 供应商的报价接口目前给到我们最大QPS是多少？还是说没有限制按照查订比那种？
    - **目前是10个QPS，技术通道说根据单量后续可以调整提升**
- 如果供应商的报价接口响应慢，对方的服务器IP是哪个地区的（国际供应商回答）？
    -  **供应商是：马来西亚，技术通道是：印度  ｜ API: apiproduction.aosconnect.com ｜ IP: 198.18.19.13  （无法查询到具体位置）｜ FTP：43.205.50.170 （Mumbai）**
- 供应商的订单下单成功是否就代表确认有房（是否即时确认）（国际供应商回答）？
    - **是的，预定成功就代表确认有房（最终会以预定详情确认是否预定成功）**
- 取消规则是否有时间相关的描述，时间是否有时区（国际供应商回答）？
    - **有时间相关描述，时间有时区**
- RatePlan层的价格是否多晚总价，是否乘以房间数之后就是订单总价？
    - **是，RatePlan层的价格是单间多晚总价,需要乘以房间数才是订单总价**
- 我们和供应商的结算币种是？
    - **MYR 马来西亚林吉特**
- 是否支持设置不同币种参数查询报价？
    - **接口支持设置不同币种，但是供应商要求只能用MYR币种**
- 是否支持设置国籍参数查询报价？
    - **接口支持设置国籍参数查询报价（入住人的国籍）**
- 是否支持多个酒店批量查询报价？最多多少个酒店？
    - **支持批量查询报价，最多支持100个酒店**
- 查询报价支持查询连住最大多少晚？
    - **支持查询连住最大30晚**
- 供应商是否存在几套价格，b2b，b2c 价格？
    - **供应商只有一套价格，默认b2b**
