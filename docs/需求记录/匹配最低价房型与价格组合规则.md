
### 搜索酒店查找匹配最低价的相同房型  , 下面是接口返回的结构示例：

每次查询酒店列表，都会返回符合查询条件的酒店列表及其房型和价格信息。以下是一个示例响应：
HotelList.HotelProperty[]  = 酒店的可选房型列表，每个房型包含以下字段：
- HotelList.HotelProperty[].DisplayRoomRate = 显示房价   酒店房型的总显示价格，通常为所有入住天数的总和。
- HotelList.HotelProperty[].SectionUniqueId = 房型唯一ID   全局唯一标识符，用于标识特定的房型选择。
- HotelList.HotelProperty[].Type = 房型类型   指示房型的类型，例如“Selection”表示可选房型。
- HotelList.HotelProperty[].RoomRates[] = 房型的具体价格信息列表，每个价格信息包含以下字段：
  - HotelList.HotelProperty[].RoomRates[].NumberOfAdults = 成人数量   预订该房型时包含的成人数量。
  - HotelList.HotelProperty[].RoomRates[].NumberOfChild = 儿童数量   预订该房型时包含的儿童数量。
  - HotelList.HotelProperty[].RoomRates[].RoomRate = 房价   该房型的单次入住价格。
  - HotelList.HotelProperty[].RoomRates[].RoomType = 房型描述   对房型的描述，例如“Deluxe, Double Or Twin Bed Room Only”。
  - HotelList.HotelProperty[].RoomRates[].MealBasis = 餐食类型   该房型包含的餐食类型，例如“Room Only”表示仅含房费。
  - HotelList.HotelProperty[].RoomRates[].MealCode = 餐食代码   用于标识餐食类型的代码，例如“RO”表示仅含房费。
  - HotelList.HotelProperty[].RoomRates[].ClassUniqueId = 房型价格唯一ID   全局唯一标识符，用于标识特定的房型价格。

### ClassUniqueId 解析规则：
"ClassUniqueId": "MTE0NzM3OF8wX3NpbmdsZXBsdXMyY2hpbGRfMV8xXzJfNTZfZGVsdXhlLCBkb3VibGUgb3IgdHdpbiBiZWRfcm9vbSBvbmx5X3RydWU="
1147378_0_singleplus2child_1_1_2_56_deluxe, double或twin床房间_only_true

按顺序解析：

1、1147378 -> 某个ID（暂不用确定）
2、0 -> 索引 0123 这种标识索引
3、singleplus2child｜single｜double｜triple｜doubleplus2child｜triplepluschild -> 预定入住人员的规格描述 ，"single", "double", "triple" 等关键词表示成人数量123个成人，plus表示加多个儿童，pluschild和plus2child代表一个儿童和2个儿童
3、1 -> 房间数量（字段：NumberOfRooms）
4、1 -> 成人数量（字段：NumberOfAdults）
5、2 -> 儿童数量（字段：NumberOfChild）
6、56 -> 儿童年龄（5岁和6岁）（字段：ChildAges）
7、deluxe, ... -> 房间描述（字段：RoomType）
8、room only -> 餐型描述（字段：MealBasis）
9、 true  ->   某个状态（暂不用确定）
